A tiny Python program that writes one roast to `/output/entry.txt`: a single original line of at most 200 characters roasting a gadget used every day — a phone that only charges when its cable is bent at one exact angle, like cracking a safe every night before bed. The line was picked by drafting fourteen candidates and duelling them pairwise on the bounty judge's own criteria — how funny the line is, how fresh the angle is, and how neatly it is worded. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
